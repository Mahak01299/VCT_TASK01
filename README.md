# VCT Practicals

## About
This repository contains practical code for the VCT course. The projects are organized into folders by topic.

## Practical Folders
- **auth-backend** — Backend files for an authentication practical.
- **college-website** — Files for a college website practical.
- **frontend** — Frontend practical files.
- **kubernetes pod task** — Files related to a Kubernetes pod task.
- **reddis server timestamp** — Files related to a Redis server timestamp practical.
- **websocket-chat** — Files for a WebSocket chat practical.

## How to Use
1. Open the folder for the practical you want to review.
2. Check that folder for its instructions and required files.
3. Follow the setup and run instructions provided with that practical.
